# W3C Community Group proposal

Submit at https://www.w3.org/community/groups/proposed/ (needs 5 supporters to launch).

**Name:** Open Mobile Document Agent Community Group

**Short name:** omda

**Description (for the proposal form):**

Phones now ship on-device models that can read documents, but there is no shared way to say what a document proves: which value came from where on the page, which deterministic check confirmed it, what the owner approved, and what may be disclosed to an app, an assistant or a verifier. This group will develop the Open Mobile Document Agent (OMDA) specification: a model-agnostic, on-device data model for evidenced assertions extracted from documents; deterministic verification (check digits, ICAO 9303 MRZ, issuer signatures); an owner-controlled store; an agent interface aligned with MCP, Android AppFunctions and iOS App Intents; and selective disclosure that reuses W3C Verifiable Credentials 2.0 and SD-JWT. The group will also maintain open registries of checks, domain profiles and models, and a synthetic conformance suite. Starting point: OMDA v0.1 draft, https://github.com/open-mobile-document-agent/open-mobile-document-agent. This is not a Standards Track group; specifications produced are Community Group Reports.

**Liaisons:** W3C Verifiable Credentials Working Group; Credentials Community Group.
